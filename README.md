## DMIT Eyeball 是什么线路？

Eyeball 这个名字听起来有点奇怪，但意思很直接：**面向"眼球"用户**，也就是普通终端用户的网络优化线路。

它的核心是 **CMIN2（中国移动二级精品网络）**，加上部分 **AS9929（中国联通精品）** 混合路由。

具体来说，洛杉矶 Eyeball 的路由策略是这样的：

- **电信去程**：AS9929 / AS58807 负载均衡
- **联通去程**：AS9929
- **移动去程**：AS58807（CMIN2）
- **三网回程**：CMIN2 + CUP 高级线路

翻译成人话就是：**三大运营商都走精品线路回来，延迟和稳定性都比普通国际线路强很多**，同时价格比 CN2 GIA 的 Premium 套餐便宜一档。

> 如果你的业务主要面向中国大陆用户，或者你经常需要从国内访问这台机器，Eyeball 线路的体感要比普通 VPS 好太多——尤其是高峰期不卡顿这一点。

## DMIT Eyeball 的几个实际使用细节

**1. 换 IP 政策**

Eyeball 套餐支持免费换 IP，但有条件：**需要 IP 被封锁（被墙）才可申请**，且每 15 天只能申请一次。这个政策还算合理，毕竟随意换 IP 会影响其他用户。

**2. 不超卖**

DMIT 明确承诺不超卖服务器资源。这也是他们套餐经常显示"无库存"的原因——卖完就是卖完，不会多塞。对用户来说这是好事：你拿到的机器性能是实打实的。

**3. 退款保障**

提供 3 天退款保证。如果你买回来测试之后发现效果不符合预期（比如你所在地区到 DMIT 节点的路由质量不好），可以申请退款，风险不大。

**4. 流量超出后的处理**

DMIT 的大多数套餐在流量耗尽后会限速而不是断网，具体限速值根据套餐不同有所差异。这比直接停机要友好很多，适合流量使用不规律的用户。
